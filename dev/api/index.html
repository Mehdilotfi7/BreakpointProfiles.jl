BreakpointProfiles.CPProfileResult — Type
CPProfileResult

Result of profiling the location of a single changepoint.

best_loss is the reference loss of the profile: the minimum of the loss at the supplied fit and of all re-optimised losses in the window, so that losses .- best_loss >= 0.

BreakpointProfiles.CPSearchSpace — Type
CPSearchSpace(center, window, n_obs; step=1, min_seg=10)

Discrete changepoint search set used by the joint profile:

T = { τ : τ_j - center_j ∈ {-window, …, window} (multiples of `step`),
      min_seg ≤ τ_j ≤ n_obs - min_seg,  τ_{j+1} - τ_j ≥ min_seg }.

The set is centred on the detected changepoints and is the same for the joint reference fit and for every profile point, so the joint profile is a proper profile over a fixed nuisance space (never above the conditional profile, because the detected changepoints belong to T). Membership is tested with in; enumerate_space lists all elements (for exhaustive search).

BreakpointProfiles.GaussianLogLikelihood — Type
GaussianLogLikelihood

Negative Gaussian log-likelihood on log-transformed observations, scaled to the -2 log L scale used by profile-likelihood methods (e.g. Data2Dynamics).

sigma is the standard deviation of the observation noise. Minimising this objective is equivalent to maximising a Gaussian likelihood, and the standard χ² threshold of 3.8415 is asymptotically valid for 95% profile-likelihood confidence intervals (Wilks' theorem).

BreakpointProfiles.GaussianLogNLL — Type
GaussianLogNLL

Gaussian negative log-likelihood on log-transformed multi-channel data, scaled to the -2 log L scale used by profile-likelihood methods (e.g. Data2Dynamics).

Each observed channel k is assumed to follow:

log(obs_k(t)) ~ N(log(sim_k(t)), σ_k²)

so the contribution is:

Σ_k Σ_t ((log(sim_k(t)) - log(obs_k(t))) / σ_k)²

Constant terms 2n * log(σ_k √(2π)) are omitted because they do not depend on the model parameters and thus do not affect the profile shape.

This formulation makes the χ² threshold of 3.8415 valid for approximate 95% profile-likelihood confidence intervals (Wilks' theorem).

BreakpointProfiles.GaussianLogNLL — Method
GaussianLogNLL(σ::Real)

Convenience: single σ applied to all channels.

BreakpointProfiles.GaussianNLL — Type
GaussianNLL(σ)

Gaussian negative log-likelihood on the original (linear) scale with known noise standard deviation, on the -2 log L scale (constants omitted):

Σ_k Σ_t ((sim_k(t) - data_k(t)) / σ_k)²

σ may be a scalar or one value per data channel. With known σ the χ²₁ threshold 3.8415 gives approximate 95% profile-likelihood intervals.

BreakpointProfiles.HybridOptimizerConfig — Type
HybridOptimizerConfig

Two-stage optimizer for rugged ODE+PLE landscapes.

Stage 1: run a global/metaheuristic optimizer (global_optimizer) to locate a good basin. Stage 2: polish the best point with a fast local optimizer (local_optimizer, e.g. OptimPLEConfig(Fminbox(LBFGS())) or NLoptPLEConfig(:LN_BOBYQA)).

It suits losses that are multimodal (global stage) but locally smooth enough for gradient/direct-search polishing, as is common for ODE models.

BreakpointProfiles.JointPLEConfig — Type
JointPLEConfig

Configuration bundle for joint adaptive PLE.

BreakpointProfiles.LaplaceLogLikelihood — Type
LaplaceLogLikelihood

Negative Laplace log-likelihood on log-transformed observations.

This corresponds to an L1 loss on log-transformed data, similar to the MICA default. Because the Laplace likelihood is not Gaussian, Wilks' theorem does not apply and the standard χ² threshold of 3.84 is not rigorously valid for 95% confidence intervals. Users of L1 losses must supply a likelihood-appropriate threshold.

BreakpointProfiles.MetaheuristicsDEConfig — Type
MetaheuristicsDEConfig

Differential-Evolution (DE) configuration using Metaheuristics.jl for the inner PLE optimisation.

DE is generally more robust than a GA on high-dimensional, rugged landscapes.

Fields:

  • population: population size N (default 150)
  • F: differential mutation factor (default 0.9)
  • CR: crossover probability (default 0.9)
  • max_evals: maximum function evaluations (default 150_000, ~1000 DE generations with N=150)
  • parallel: run population evaluations in parallel with Threads.@threads (default true)
BreakpointProfiles.MultiStartBOBYQAConfig — Type
MultiStartBOBYQAConfig

Multi-start BOBYQA (Bound Optimization BY Quadratic Approximation) for the inner PLE optimisation.

Runs BOBYQA from n_starts initial points: the warm-start x0 plus n_starts - 1 randomly perturbed copies. Returns the best result across all starts. This mitigates the risk of BOBYQA getting trapped in a local minimum.

BOBYQA is derivative-free and builds a quadratic interpolation model, making it well suited to stiff ODE objectives where gradients are unreliable or the loss landscape has discontinuities (solver failures → Inf).

Recommended settings for PLE of 30-70 dimensional ODE models:

  • n_starts = 5
  • maxeval = 2000
  • xtol_rel = 1e-6
  • perturbation = 0.1 (±10% of bound range)
BreakpointProfiles.NLoptPLEConfig — Type
NLoptPLEConfig

Direct-search configuration via NLopt for the inner PLE optimisation.

Default is LN_BOBYQA. NLopt is useful if both GA and gradient methods fail.

BreakpointProfiles.ODEChangepointPLEProblem — Type
ODEChangepointPLEProblem{F,M,OF,D,L}

Container for a profile-likelihood problem involving an ODE model with a fixed set of changepoints.

Fields

  • objective: function (params, changepoints) -> scalar loss. If provided, it is used directly by the profiler. Otherwise the package falls back to simulator or to the generic ODE segment solver.
  • simulator: optional function (params, changepoints) -> simulation matrix.
  • ode_function: ODE RHS (du, u, p, t) for the generic segment solver. Inside segment j the solver passes p = [θ_global; θ_segment_j], i.e. the n_global global parameters followed by the n_segment_specific parameters of the active segment, so the right-hand side never needs to know the changepoint locations.
  • u0: initial condition for the generic solver.
  • tspan: time span (t0, tf) for the generic solver.
  • data: observed data, channels × time.
  • loss_fn: likelihood or loss callable (sim, data) -> scalar.
  • changepoints: sorted vector of detected changepoint indices.
  • best_params: best-fit parameter vector for the current changepoints.
  • best_loss: loss evaluated at best_params.
  • lb, ub: lower and upper bounds for all parameters (global + segment-specific).
  • param_names: vector of parameter labels.
  • n_global: number of global parameters.
  • n_segment_specific: number of segment-specific parameters per segment.
  • n_obs: number of time points.
BreakpointProfiles.OptimPLEConfig — Type
OptimPLEConfig

Gradient-based optimisation configuration for the inner PLE optimisation.

Default is Fminbox(LBFGS()). This can be fast on smooth models but may fail on stiff epidemiological models.

BreakpointProfiles.ProfileOptions — Type
ProfileOptions

D2D-style configuration for 1-D profile-likelihood exploration.

Fields

  • samplesize: maximum number of outward steps per direction (D2D default: 100).
  • rel_step_increase: target initial Δloss / threshold_margin for choosing the next step size (D2D default: 0.1).
  • step_factor: factor by which the step is increased/decreased during step-size bracketing (D2D default: 1.5).
  • min_step_factor: minimum step as a fraction of the parameter range.
  • max_step_factor: maximum step as a fraction of the parameter range.
  • stop_margin_factor: stop profiling in a direction when Δloss exceeds stop_margin_factor * threshold_margin (D2D default: 1.2).
  • polish: if true, polish the result of every global/metaheuristic inner optimization with a local optimizer (LBFGS/BOBYQA).
  • allow_better_optimum: if true and profiling finds a loss lower than the reference best_loss, replace the reference with the better optimum and restart profiling (see max_reference_updates).
  • smooth_jumps: if true, apply D2D pleSmooth-style post-processing to remove local jumps caused by sub-optimal inner optimizations.
  • jump_tol: Δloss drop used to flag a local jump during smoothing.
  • max_trial_redos: maximum number of step-size reductions per outward step.
  • refine_ci: if true, refine each threshold crossing by bisection with re-optimisation, so the reported CI endpoint does not depend on the profile grid spacing.
  • ci_refine_iters: maximum number of bisection steps per crossing.
  • refit_reference: if true, re-optimise all free quantities from best_params before profiling so the profile is anchored at an optimum.
  • max_reference_updates: when allow_better_optimum is true and a profile finds a loss below the reference by more than better_optimum_tol, the reference is replaced and profiling restarts (at most this many times).
  • better_optimum_tol: absolute loss tolerance for declaring a better optimum.
BreakpointProfiles.ProfileResult — Type
ProfileResult

Result of profiling a single scalar parameter.

Fields

  • parameter: label of the profiled parameter.
  • index: position in the parameter vector.
  • best_value: MLE value of the profiled parameter.
  • best_loss: reference loss (MLE).
  • ci_lower, ci_upper: approximate 95% CI bounds.
  • identifiable: true if the profile crosses the threshold on both sides.
  • threshold: best_loss + χ²(1, 0.95).
  • values, losses: the full profile curve.
  • n_failed: number of grid points where the inner optimizer returned Inf.
  • best_found_loss: lowest loss found during profiling (may be < best_loss if the reference optimum was not the true MLE).
  • best_found_params: full parameter vector at best_found_loss.
  • cps_trace: changepoint vector used at each profile point (constant for conditional profiles, re-optimised for joint profiles).
  • params_trace: full optimised parameter vector at each profile point (empty for results built without it). Used by extend_profile to continue a profile without recomputing it.
  • profile_lb, profile_ub: range over which the parameter was profiled (the problem bounds, or the extended range after extend_profile); -Inf/Inf when unknown.
BreakpointProfiles.ProfiledGaussianNLL — Type
ProfiledGaussianNLL()

Gaussian -2 log L with a common unknown σ profiled out analytically:

N · log(RSS / N)

where RSS is the residual sum of squares over all non-missing observations and N their number. This is the likelihood implied by the MICA BIC N log(RSS/N) + p log N, so detection and profiling use the same likelihood; the χ²₁ threshold applies directly on this scale.

BreakpointProfiles._engine_smooth! — Method
_engine_smooth!(tr, idx, inner, tol)

D2D pleSmooth equivalent. Walking outward from the profile minimum the profile should not decrease; if a point is higher than its outer neighbour by more than tol, it is re-optimised warm-started from the outer neighbour's optimum (the inner point was trapped in a worse local optimum). Improvements propagate inward. Repeated until no point improves (at most 5 sweeps).

BreakpointProfiles._joint_inner — Method
_joint_inner(prob, idx, space, optimizer; parallel=false, cp_search=:grid, mode_starts)

Inner solver of the joint profile: minimise over all free parameters and over changepoint vectors in the fixed search set space.

  • cp_search = :grid – exhaustive search: every CP vector is optimised from the warm start and the best is returned.
  • cp_search = :local – coordinate search starting from the warm CP vector: move single changepoints by one step while the loss improves. Much cheaper (needed for many changepoints) but can miss a distant better configuration.

BreakpointProfiles._profile_engine — Method
_profile_engine(prob, idx, ref_params, ref_cps, ref_loss, margin, inner, options;
                samplesize=options.samplesize)

D2D-style adaptive profile (Raue et al. 2009; Data2Dynamics ple.m).

For each direction:

  1. Propose value ± step.
  2. Trial step: evaluate the loss at the proposal with all nuisance quantities held at the current profile point (no re-optimisation) and shrink the step by step_factor until the increase relative to the current point is at most rel_step_increase * margin.
  3. Re-optimise the nuisance quantities with inner and record the point.
  4. Enlarge the step by step_factor and continue until the profile exceeds stop_margin_factor * margin above the reference or a bound is hit.

reach = (lo, hi) forces the lower (upper) direction to continue at least to lo (hi) even after the threshold has been exceeded; it is used by the joint profile to reach admissible secondary modes so that disconnected confidence regions are not missed.

Afterwards local jumps are smoothed (D2D pleSmooth), each threshold crossing is refined by bisection, and the CI is read off the refined profile. Returns (ProfileResult, trace).

BreakpointProfiles.cp_ci — Method
cp_ci(cp_prof::CPProfileResult, threshold)

Return (ci_lower, ci_upper, identifiable) for a changepoint profile, where [ci_lower, ci_upper] is the contiguous component of the confidence set that contains the profile minimum and identifiable is true only if the whole confidence set is bounded inside the profiling window (not censored at either window edge). BreakpointProfiles.cp_confidence_set — Function
cp_confidence_set(cp_prof::CPProfileResult[, threshold]; delta=3.8415)

Confidence set for a changepoint location: all candidate locations whose profile loss is at most threshold (default cp_prof.best_loss + delta).

Returns a named tuple with fields

  • set – all candidate locations in the confidence set,
  • lower, upper – the contiguous component containing the profile minimum,
  • components – all contiguous components (vectors of locations),
  • censored_lower, censored_upper – true if the set reaches the first/last candidate examined, i.e. the profile was not observed to rise above the threshold on that side (the set may extend beyond the window),
  • identifiable – true if the set is bounded on both sides inside the window (!censored_lower && !censored_upper),
  • best_cp – candidate with the minimum profile loss.

Note: the χ²₁ calibration is heuristic for a discrete changepoint location (non-regular parameter); a parametric bootstrap gives calibrated sets.

BreakpointProfiles.extend_profile — Method
extend_profile(prob, profile; side=:both, left=0.5, right=0.5, mode=:range,
               only_open=true, options=ProfileOptions(),
               optimizer=default_multistart_bobyqa_config(),
               samplesize=options.samplesize) -> ProfileResult

Continue an existing conditional (or baseline) profile beyond the bounds of the profiled parameter, to check whether an interval that is open at a bound closes further out.

  • Existing points are kept. The walk starts from the outermost computed point on each extended side, warm-started from its optimised parameters, and only the new region is computed. The new points are merged with the old ones; jump smoothing and the bisection of threshold crossings (if enabled in options) then run on the merged profile, and the CI and identifiable are recomputed for the extended range.
  • Relative amounts. left/right are fractions (0.5 = 50 %), interpreted by mode (see extended_bounds): :range extends by a fraction of the current range, :relative by a fraction of the bound value.
  • Sides. side = :left, :right or :both; with :both the two sides may use different amounts. With only_open = true (default) a side is extended only if the profile is open there (see profile_open_sides).
  • Only the profiled parameter may leave its bounds; all other parameters keep the bounds of prob during re-optimisation.
  • The reference (best_loss, threshold) is not changed. If the extension finds a loss below the reference, a warning is issued: the optimum lies outside the original bounds and the whole analysis should be redone with wider bounds.

prob must be the problem the profile was computed for (for profiles from profile_all_parameters with refit_reference=true, the reference may have been re-fitted; the extension uses the profile's own best_loss and points). Joint profiles (profile_parameter_joint) are not supported.

Returns a new ProfileResult whose profile_lb/profile_ub give the range actually profiled.

BreakpointProfiles.extend_profiles — Method
extend_profiles(prob, profiles; kwargs...) -> Vector{ProfileResult}

extend_profile for every profile (same keyword arguments; with the default only_open = true closed profiles are returned unchanged). Profiles are extended in parallel with Threads.@threads unless the optimiser is itself threaded. Compare before and after with extension_summary.

BreakpointProfiles.extended_bounds — Method
extended_bounds(lo, hi; left=0.0, right=0.0, mode=:range) -> (new_lo, new_hi)

New profiling range for a parameter currently profiled over [lo, hi]. left and right are relative amounts (0.5 = 50 %), never raw values, so the same setting works for parameters on different scales:

  • mode = :range (default) – extend by a fraction of the current range: new_lo = lo - left * (hi - lo), new_hi = hi + right * (hi - lo).
  • mode = :relative – extend by a fraction of the bound itself, multiplicatively: new_lo = lo / (1 + left), new_hi = hi * (1 + right). Requires lo > 0 (for left > 0) and hi > 0 (for right > 0); the lower bound stays positive, so this suits positive rate constants and scales.
BreakpointProfiles.extension_summary — Method
extension_summary(before, after) -> DataFrame

One row per parameter: profiling range, interval, identifiability and open sides before and after extend_profiles. The number of parameters that became identifiable is count(df.identifiable_after .& .!df.identifiable_before).

BreakpointProfiles.joint_grid_fit — Method
joint_grid_fit(prob, window, optimizer; kwargs...)

As joint_reference_fit, but returns a named tuple with the joint optimum (best_loss, best_params, best_cps) and the optimum at every changepoint vector of the search set (grid, losses, params). The per-grid optima are used by the joint profile to locate secondary modes of the confidence region.

BreakpointProfiles.joint_reference_fit — Method
joint_reference_fit(prob, window, optimizer; step=1, min_seg=10,
                    parallelize_grid=true, n_starts=3, perturbation=0.3,
                    extra_starts=Vector{Float64}[], seed=nothing)

Jointly re-fit all parameters and the changepoint locations over the fixed CP set T (see _joint_cp_grid) to obtain the joint maximum-likelihood estimate. Each CP vector is optimised from prob.best_params, from n_starts - 1 random perturbations of it (±perturbation of the bound range), and from every vector in extra_starts. The result is never worse than the loss at (prob.best_params, prob.changepoints).

Returns (best_loss, best_params, best_cps).

BreakpointProfiles.profile_all_parameters — Method
profile_all_parameters(prob; options=ProfileOptions(),
                       optimizer=default_multistart_bobyqa_config(),
                       indices=nothing, threshold=nothing, delta=nothing,
                       method=nothing, n_points=nothing)

Conditional profiles of every parameter (or of indices). All profiles share one reference fit: the reference is re-fitted once (options.refit_reference) and, if any profile finds a better optimum, the reference is replaced and all profiles are recomputed (options.allow_better_optimum). BreakpointProfiles.profile_all_parameters_joint — Method
profile_all_parameters_joint(prob; options=ProfileOptions(), window=7, step=1,
                             min_seg=10, optimizer=default_multistart_bobyqa_config(),
                             indices=nothing, threshold=nothing, delta=nothing,
                             parallel_over_parameters=true, cp_search=:grid,
                             reference_extra_starts=Vector{Float64}[], n_points=nothing,
                             joint_reference=nothing, grid_fit=nothing)

Joint profiles of every parameter (or of indices), all anchored at one joint reference fit. If any profile finds a better optimum, the joint reference is replaced and all profiles are recomputed (options.allow_better_optimum).

Keyword arguments (besides those of profile_parameter_joint):

  • window, step, min_seg: the changepoint search set — every changepoint may move within ±window of its detected position in steps of step, and no segment may be shorter than min_seg. A window that is too narrow cuts the profile off; a wide window with several changepoints makes the grid large.
  • cp_search: :grid optimises every changepoint vector of the search set at each profile point (exact, cost grows with the grid size); :local uses a coordinate search from the current changepoints (much cheaper, may miss distant modes).
  • parallelize_grid: fit the changepoint vectors of the grid in parallel threads (ignored for optimisers that are threaded themselves).
  • parallel_over_parameters: profile the parameters in parallel threads.
  • reference_extra_starts: additional starting vectors for the joint reference fit (useful when the default starts miss the global optimum).
  • joint_reference: a precomputed (loss, params, cps) joint optimum; skips the reference fit.
  • grid_fit: a precomputed result of joint_grid_fit; skips the grid fit and supplies the secondary modes used to find disconnected intervals.
BreakpointProfiles.profile_changepoint — Method
profile_changepoint(prob::ODEChangepointPLEProblem, cp_idx::Int;
                    window=7, min_seg=10,
                    optimizer=default_multistart_bobyqa_config(), polish=true)

Profile the location of the cp_idx-th changepoint: move it over original_cp ± window (the other changepoints stay fixed), re-optimise all parameters at every candidate location, and record the loss.

Candidates closer than min_seg to the data boundaries or to a neighbouring changepoint are skipped. Candidates are visited outward from the detected location; each is optimised both from prob.best_params and from the optimum of its inner neighbour, and the better result is kept.

The profile reference best_loss is the minimum over the loss at prob.best_params and all profile values, so losses .- best_loss ≥ 0. Returns a CPProfileResult.

The profile CI reported in p.ci_lower/p.ci_upper is the component containing the estimate; additional components indicate a disconnected (multimodal) confidence region.

BreakpointProfiles.profile_parameter — Method
profile_parameter(prob::ODEChangepointPLEProblem, idx::Int;
                  options=ProfileOptions(),
                  optimizer=default_multistart_bobyqa_config(),
                  threshold=nothing, delta=nothing,
                  method=nothing, n_points=nothing)

Conditional profile likelihood of parameter idx: the changepoints are held fixed at prob.changepoints and all other parameters are re-optimised at each profile point.

The confidence threshold is reference_loss + delta. delta defaults to the χ²₁ quantile 3.8415 (valid when the loss is -2 log L of a correctly specified likelihood). Alternatively an absolute threshold can be supplied; it is converted to a margin relative to the loss at prob.best_params.

With options.refit_reference the reference is first re-optimised; with options.allow_better_optimum the profile is restarted from any better optimum it discovers (up to options.max_reference_updates times).

Keyword arguments:

  • options: stepping, smoothing and CI settings, see ProfileOptions.
  • optimizer: inner optimiser used at every profile point (the main driver of runtime and of profile quality).
  • delta / threshold: confidence level, as described above.
  • method: :adaptive (default, D2D-style adaptive steps) or :fixed (a fixed grid of n_points values around the estimate, clipped to the bounds: log-spaced over [best/5, 5·best] when the parameter is positive and its bounds span more than a factor 10, otherwise linear over best ± half the bound range).
  • n_points: for :adaptive, overrides options.samplesize (maximum steps per direction); for :fixed, the number of grid points (default 20).

A profile that is open at a parameter bound can be continued beyond it with extend_profile.

BreakpointProfiles.profile_parameter_joint — Method
profile_parameter_joint(prob::ODEChangepointPLEProblem, idx;
                        options=ProfileOptions(), window=7, step=1, min_seg=10,
                        optimizer=default_multistart_bobyqa_config(),
                        threshold=nothing, delta=nothing, joint_reference=nothing,
                        cp_search=:grid, parallelize_grid=true, n_points=nothing)

Joint profile likelihood of parameter idx: at every profile point the loss is minimised over all other parameters and over the changepoint locations in the fixed set T (all CP vectors within ±window of the detected changepoints, spacing step, minimum segment length min_seg).

The profile is anchored at the joint MLE over T (joint_reference, computed with joint_reference_fit if not supplied) and the threshold is joint_reference_loss + delta (default delta = 3.8415). Every joint profile value is a minimum over a superset of the conditional problem, so the joint profile never lies above the conditional profile; because the joint reference can also be lower than the conditional one, joint intervals are usually, but not necessarily, wider than conditional intervals.

Uses the same adaptive stepping, smoothing, and bisection refinement as profile_parameter. Returns a ProfileResult whose cps_trace records the optimal changepoints at each profile point.
